# 🌸 Jocélia Perfumes

Catálogo web moderno, elegante e responsivo desenvolvido para a revenda independente de fragrâncias, body splashes e loções corporais. O projeto conta com links diretos para atendimento e fechamento de pedidos via WhatsApp e Instagram.

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **Tailwind CSS** (Estilização moderna e responsiva via CDN)
* **Font Awesome** (Ícones para redes sociais e botões de ação)
* **SVG Vector Art** (Ilustrações de produtos personalizadas em alta resolução)

## ✨ Funcionalidades

* 📱 **Design Responsivo:** Adaptado perfeitamente para celulares, tablets e computadores.
* 🛍️ **Vitrine de Produtos:** Exibição detalhada de itens com status (Novos Lacrados e Desapegos).
* 💬 **Integração com WhatsApp:** Botões de compra direta com mensagens pré-formatadas para facilitar o atendimento.
* 🔗 **Redes Sociais:** Links integrados para o Instagram oficial da marca.

## 🎨 Paleta de Cores
O design foi cuidadosamente inspirado na estética suave e sofisticada do universo da perfumaria feminina (tons de rosa suave, branco e detalhes contrastantes escuros).
